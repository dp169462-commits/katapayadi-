What is Katapayadi?

Ancient number system meets modern web technology

🏛 Ancient System

Katapayadi is an ancient Indian system where Sanskrit consonants were associated with numbers. It was used especially in Kerala for remembering astronomical numbers and calculations.

🔐 Our Cipher

This project converts letters into Katapayadi-inspired numbers and then adds a keyword-based shift. The same keyword can be used to decrypt the message.
